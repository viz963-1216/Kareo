# KUI-r3 公開資源篩選驗證（2026-10-13）

Jerry 指示移除特約縣市篩選並檢查其餘條件。此次只調整前端篩選、網址還原與產品紀錄；未刪除機構特約事實、修改 API／資料庫／推薦規則或啟用 D-05。

## 發現與修正

1. 特約縣市從表單、LookupForm 及前端建出的 request 移除。既有 `contractCity` API 契約及卡片特約資訊保留；舊網址參數不成为隱藏限制。
2. 查詢條件／頁碼原本只在頁面狀態，詳細頁返回可能失去。改以已套用的公開查詢 URL 還原，支持詳細頁返回、重新載入、瀏覽器上一頁／下一頁。返回連結使用白名單，不帶未知查詢參數、評估回答或座標。
3. 切換輔具資源中心時，原本可沿用服務範圍條件而不必要排除中心。現在清除服務類別／輔具分類／未確認條件，固定依所在地查詢，停用不適用控制項。
4. 地區方式移除重複的「使用預設」選項，只保留機構所在地／已確認服務範圍，明示後者可包含位於其他區的機構。切換縣市仍清除行政區，非輔具服務仍清除輔具分類。
5. 只在 SERVICE_AREA 結果中分組已確認／待確認機構。依所在地或中心查詢使用一般資源列表，避免把中心呈現成到府服務範圍待確認。
