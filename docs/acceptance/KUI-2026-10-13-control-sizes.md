# KUI-r4 — 長照資源篩選尺寸修正

Jerry 2026-10-13 要求篩選控制項保持一致大小。範圍限資源查詢表單 CSS，沿用 TASK-KUI-REDESIGN 的允許路徑。

## 問題與修改

線上 Chrome 1440px 實測：縣市、行政區選單因同列說明文字使 label 網格伸展，高 76.390625px；其他選單高 48px，搜尋框 51.59375px，操作按鈕 54.390625px。查詢與清除寬度分別為 72.796875px／108.796875px。

現在 label 的內容靠上排列，不把剩餘高度分配給文字或選單；選單、搜尋框、兩個操作按鈕使用共用 48px 高度及相同垂直內距。操作按鈕桌面兩欄等寬、手機單欄滿寬。保留文字說明完整換行、disabled、focus 及原本篩選行為。

## 實測

- 前端 typecheck、97 項既有測試、public-resources 正式產物建置及 check-public-site 全部通過。低影響樣式修正不另新增只比對 CSS 字串的測試。
- 本機正式產物經唯讀代理使用真實公開 API。1440px：6 個選單皆 355.40625 × 48px，同列頂端對齊；搜尋框 726.8125 × 48px；兩按鈕皆 378 × 48px。
- 輔具中心模式新增說明並停用相關欄位後，6 個選單仍全為 355.40625 × 48px，同列對齊。
- 375px：6 個選單與搜尋框皆 301.8125 × 48px，兩按鈕皆 343 × 48px；頁面 scrollWidth = innerWidth = 375，無水平溢出。測試後已重設 viewport。
- 原查詢及清除按鈕可操作，清除還原全部資源及預設條件。無新增資料庫、API、資料集或正式同意變更。
