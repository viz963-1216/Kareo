# Kareo 網站介面規則（KUI-r1）

依 Jerry 提供的 `KAREO_WEBSITE_REDESIGN_SPEC.md` 漸進改版。平台定位為一站式長照資訊整合：整理可能需求、查制度與雙北資源，協助與個管師或 1966 討論；不核定資格、補助或醫療診斷。

## 共用視覺

來源：`apps/web/src/styles.css` 的 `--kareo-*` 變數。

| 項目 | 規則 |
| --- | --- |
| 主色／主按鈕 | `#1f5b48`；文字白色 |
| 內文／背景／卡片 | `#20362f`／`#f5f8f3`／`#ffffff` |
| 焦點 | `#005fcc`，3px 外框及 2px 間距；不得移除 |
| 內文／行高 | 18px／1.6 |
| 主標題 | 桌面 36px、手機 28px |
| 區塊標題 | 24px |
| 間距 | 8、16、24、32px |
| 表單與按鈕 | 最低高度 48px；勾選文字整列可操作，目標最低 44px |
| 字標 | 既有「Kareo 長照一點通」文字標誌，維持字形比例與首頁連結 |

首頁只保留一個最高強度 CTA；制度、資源、1966 與交通預約為次要行動。資訊頁與表單依各自任務提供主要按鈕。沿用绿白卡片，不新增無授權照片、假認證標章或未實現的服務承諾。營運者與資料聯絡資訊沿用隱私頁；不另建立真人客服承諾。

## 元件狀態

- 按鈕：一般、hover、鍵盤 focus、disabled、載入時 disabled；不可僅靠顏色說明狀態。
- 表單：標籤與選項、選填提示、48px 控制項；初始回答為 UNKNOWN；錯誤用文字並移動焦點。
- 資訊：載入中、已開放有內容、無符合內容、沒有發布版本、暫時故障、明確設定的籌備中分開顯示。HTTP 404 不推論為「尚未開放」。
- 故障：有效重試、首頁、公開資源與 `tel:1966`。籌備中不提供無效的篩選或重試。
- 卡片：真實來源機關、來源連結、發布／生效／查核日期、Kareo 整理標示；缺資料為「待補」。日期採臺北時區。

## 行為界線

公開正式網址提供真實資料查詢及分頁內初步分析。回答與選填地址不送出雲端個案寫入、不使用 GPS、不提供正式媒合；重新整理或重新開始清除分頁狀態。兩步往返保留回答，結果可返回修改。完整 D-05／J-003 的驗收條件另依既有文件，視覺改版不改其核准狀態。

實測日期、尺寸、對比、操作結果與限制記錄於 `docs/acceptance/KUI-2026-10-12-redesign.md`。部分工程測試通過不代表全站 WCAG 2.2 AA 認證。真實使用者理解程度另依五人測試記錄。
